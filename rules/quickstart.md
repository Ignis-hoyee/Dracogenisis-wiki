# 快速开始

欢迎来到《飞龙秘境》非官方 Wiki！

## 设置流程

### 地图设置

1. 放置中心地图。
2. 将10个地图板进行混洗。
3. 抽取3张地图板块，翻至B面，按图示进行拼接。
4. 根据玩家人数，抽取一定数量的地图板块，翻到A面，按下表所示方式进行拼接。
  
    | 玩家人数 | 拼接方式 |
    | --- | --- |
    | 2人游戏 | [2人游戏方案(占位符)](/public/images/tokens/2playersSetup.jpg) |
    | 3人游戏 | [3人游戏方案(占位符)](/public/images/tokens/2playersSetup.jpg) |
    | 4人游戏 | [4人游戏方案(占位符)](/public/images/tokens/2playersSetup.jpg) |

5. 若为4人对局时，最后1个剩余的地图板块翻至B面，作为空岛放置在边上，并在岛上带有狩猎奖励的地块各添加1个对应的临时资源。

### 纪年板块设置

1. 放置季节指示物到年历的第一年位置。
2. 随机抽取4个纪念碑板块防止到纪念碑区域。
3. 玩家按任意的方式决定初始顺位，并根据自己选取的角色颜色放置到对应顺位标记上。然后3号位玩家获得1个食物，4号位玩家获得1个金币。
